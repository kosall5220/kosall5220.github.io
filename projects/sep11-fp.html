SEP11 Freedom Project (Time Capsule App)

Context

In my SEP (Software Engineering Program) class I had to complete a year-long project. Throughout the year I independently learned how to use a Javascript tool and combined it with everything I learned from class to create my own app. This year-long project I completed in 11th grade is known as the SEP11 Freedom Project.

Process

  1. Before doing anything I first needed to know what I wanted to make. The idea I came up with originally was an app where users can write a message to their future self and preserve important memories. Later on, this app turned into an online blog where all messages are displayed publicly and can be seen by anyone.

  2. Next, I had to pick a tool to create this app. The tool I chose was Firebase. I picked this too because it has a realtime database feature which will store documents in real time. I imagined using Firebase to create a database for storing the messages/entries that the users write.

  3. After picking a tool, I had to learn how to use it. I spent a few weeks tinkering with Firebase and I logged what I learned in this “learning log”.

  4. Then I used Firebase, HTML, and JavaScript to help me make a minimum viable product (MVP) or a prototype of my app. This included things like an entry counter, a delete and add button, and the messages being displayed on screen when the user adds an entry.

  5. Lastly, I went beyond my MVP by decorating the app and adding extra features like a navbar, scroll up button, and an “are you sure” pop us that appears when you try to delete an entry.

More details about my process can be found here: SEP11 Freedom Project Blog
